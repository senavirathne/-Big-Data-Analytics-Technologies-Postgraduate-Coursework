# Coursework Verification Runbook

**Testing and Submission Guidelines:**

* **Commit First:** Ensure all code is fully committed to Git before running any tests.
* **Run Tests:** Execute the automated tests for Tasks 1–5 using either GitHub Actions or local Docker containers.
* **Verify Evidence:** Confirm all tests pass and that the generated evidence manifests match your exact Git commit SHA.
* **Submit:** Keep the generated logs and artifacts for your final coursework submission. Do not commit large database files or generated data to the repository.
